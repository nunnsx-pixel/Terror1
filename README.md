# 📹 Projeto: A Última Live (Found Footage Horror)

Roteiro imersivo de terror em formato **POV (Primeira Pessoa)**, dividido em 2 partes de 60 segundos, otimizado para **TikTok** e **YouTube Shorts**.

## 📌 Especificações Técnicas
* **Formato:** Vídeo vertical (9:16)
* **Duração Total:** 2 minutos (Parte 1: 60s | Parte 2: 60s)
* **Estilo Visual:** POV limpo (visão em primeira pessoa), HUD de gravação no canto superior direito (`02:43 AM 🔴 REC`), sem tela preta no início (abertura direta na ação).
* **Gênero:** Terror psicológico / Suspense de exploração urbana.
